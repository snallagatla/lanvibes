# LanVibes logo options

Open index.html to compare all three concepts. Each icon is a self-contained, transparent SVG with editable geometry. The wordmark files retain editable text using Inter / Segoe UI / Arial; outline the chosen lettering before final production if exact cross-platform typography is required.

PulseLink emphasizes network health. WaveVibe emphasizes personality and an S-shaped signal current. LAN Orbit emphasizes connectivity and a professional identity. These are exploratory alternatives; the installed application branding has not been changed.
