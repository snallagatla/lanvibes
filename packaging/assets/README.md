# LanVibes brand assets

An original geometric LV monogram uses round terminals as network nodes. Mint (`#5EF0C1`) and sky blue (`#65BFFF`) contrast with a dark navy tile (`#102639`).

- `agent/wwwroot/lanvibes.svg`: scalable dashboard logo and favicon.
- `lanvibes.png`: installer artwork and preview.
- `lanvibes.ico`: seven Windows icon sizes, embedded into the executable and installers.
- `lanvibes.icns`: macOS app icon with 128–1024 pixel images.

Run `packaging/build-brand-assets.ps1` on Windows to regenerate bitmap icon formats from the same geometry. Keep the SVG geometry in sync if changing the design.
