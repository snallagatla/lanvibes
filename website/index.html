FROM QUESTION TO OBSERVATION

Open. Inspect. Share.

01

Open the app

LanVibes opens a dashboard in your browser and reads local DNS configuration. An internet connection isn’t needed to view local settings.

02

Run the checks you need

Choose Home, Office, or VPN. Run network tests when you’re ready; external checks contact configured test services.

03

Bring context to support

Export the collected configuration and results as a JSON report. You choose where to save it and how to share it with your support team.

Local by design.

This website provides product information and downloads. Diagnostics run in the installed app on your workstation. Reports are saved locally and aren’t uploaded automatically. Network tests contact their configured endpoints only when requested.

Quit when you’re finished. The local session also stops after 15 minutes without local requests; an active request prevents idle shutdown.
